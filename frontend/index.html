游戏控制

Minimax 设置

纯规则搜索（expectiminimax + alpha-beta，已升级：多特征评估 / 置换表 / 走子排序 / 静态搜索）。

强引擎设置

αβ + Star1 + 置换表 + 迭代加深的纯计算强引擎（移植 misty-banqi），节点预算越高越强、耗时越长。

启发式 MCTS 设置

Gumbel MCTS + 纯计算多特征启发式评估（无需 torch/模型）。

MCTS+DL 设置（TorchScript / ONNX）

提示：先加载模型（.pt 走 MCTS+DL，.onnx 走 MCTS+ONNX），再选择对应对手开始新游戏。可手动输入模型路径以加载子目录中的模型。

NNUE 设置（Expectimax + .nnue）

加载 .nnue（如 python/outputs/4x4/nnue_loop/best.nnue）后开始新游戏；模型特征维度需与所选变体匹配。
